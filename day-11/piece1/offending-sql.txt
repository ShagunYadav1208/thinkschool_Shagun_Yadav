For comparison, the FIXED endpoint (/authors-summary-fast) issues exactly one command for the same
logical result:

info: Microsoft.EntityFrameworkCore.Database.Command[20101]
      Executed DbCommand (21ms) [Parameters=[], CommandType='Text', CommandTimeout='30']
      SELECT [a].[AuthorId], [a].[Name], (
          SELECT COUNT(*)
          FROM [Quotes] AS [q]
          WHERE [q].[AuthorId] = [a].[AuthorId]) AS [quoteCount]
      FROM [Authors] AS [a]

EF Core compiles the LINQ projection's per-author subquery into a correlated SQL subquery that SQL
Server executes as part of ONE query plan (see execution-plan-fixed.txt) - not as 1,000 separate
round trips issued by the application.
